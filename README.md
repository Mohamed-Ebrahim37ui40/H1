## 💡 فكرة البرنامج

**Firmo (Firmo)** هو مجموعة أدوات زراعية عملية في تطبيق واحد، تساعدك على حساب ومتابعة أهم عمليات الري والزراعة والحصاد بدقة وسرعة، حتى وأنت في الحقل بدون إنترنت.

### الأدوات المتوفرة:

| الأداة | الوصف |
|--------|-------|
| 📐 **مساحة البيفوت** | حساب مساحة نظام الري المحوري (Pivot) بدقة حسب القطر أو نصف القطر |
| 💧 **تجربة الري** | تسجيل ومتابعة تجارب الري وتوزيع المياه |
| 🥔 **فحص التقاوي** | فحص جودة التقاوي وحساب عدد الدرنات والنسب |
| 🌱 **متابعة الإنبات** | متابعة نسبة الإنبات يوم بيوم |
| 🚜 **تجربة الحصاد** | تسجيل نتائج تجارب الحصاد والإنتاجية |
| 🔍 **فحص البيفوت** | فحص حالة نظام البيفوت وتسجيل الملاحظات |

كل البيانات تُحفظ تلقائياً على جهازك، ويمكنك عمل نسخة احتياطية واسترجاعها في أي وقت.

## 🚀 خطوات التثبيت (مرة واحدة فقط)

### 1️⃣ ارفع الملفات على GitHub

ارفع **كل الملفات بنفس الهيكل** التالي (مهم جداً):

```
📁 المستودع
 ├── index.html
 ├── about.html
 ├── sw.js
 ├── manifest.webmanifest
 ├── README.md
 └── 📁 icons
      ├── icon-192.png
      ├── icon-512.png
      ├── maskable-512.png
      ├── apple-touch-icon.png
      └── favicon-32.png
```

> ⚠️ لا ترفع الأيقونات في الجذر. لازم تكون داخل مجلد اسمه `icons`.

### 2️⃣ فعّل GitHub Pages

1. ادخل على المستودع → **Settings**
2. من القائمة الجانبية اختر **Pages**
3. تحت **Source** اختر **Deploy from a branch**
4. Branch: `main` (أو `master`) و Folder: `/ (root)`
5. اضغط **Save**

بعد دقيقة أو دقيقتين هيظهر الرابط:
`https://USERNAME.github.io/REPO-NAME/`

### 3️⃣ ثبّت التطبيق على جهازك

#### على الكمبيوتر (Windows / Linux / Mac – Chrome أو Edge):
- افتح الرابط
- انتظر 20–30 ثانية
- اضغط على أيقونة التثبيت 📲 في شريط العنوان (شكل شاشة مع سهم للأسفل)
- أو من القائمة `⋮` → **Install this site as an app** / **تثبيت هذا الموقع كتطبيق**

#### على الأندرويد (Chrome):
- افتح الرابط
- اضغط زر 📲 داخل التطبيق، أو من قائمة المتصفح → **تثبيت التطبيق** / **Add to Home screen**

#### على الآيفون / الآيباد (Safari):
- افتح الرابط
- اضغط زر المشاركة (المربع مع السهم)
- اختر **إضافة إلى الشاشة الرئيسية**

## 📱 بعد التثبيت

- التطبيق يظهر كبرنامج عادي في قائمة التطبيقات
- يعمل **بدون إنترنت** بعد أول فتح
- كل أدواتك وبياناتك محفوظة على الجهاز
- اضغط زر 💾 بشكل دوري لعمل نسخة احتياطية (ملف JSON)

---

## 🔄 تحديث التطبيق

لما ترفع نسخة جديدة:
1. غيّر رقم النسخة داخل ملف `sw.js` (مثلاً من `firmo-v1` إلى `firmo-v2`)
2. ارفع الملفات
3. افتح التطبيق → هيظهر تنبيه "تم تحديث التطبيق" → أعد فتحه

---

## 🛠️ ملاحظات مهمة

- لازم الاستضافة تكون **HTTPS** (GitHub Pages توفرها تلقائياً)
- فتح الملف مباشرة من الجهاز (`file://`) **مش هيشتغل** كـ PWA
- البيانات محفوظة محلياً فقط، خد نسخة احتياطية دورياً
